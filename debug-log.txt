# Debug Log: JUnit Tests Failing on JDK 25 with Mockito

## Environment
- OS: Windows 11
- JDK: 25.0.1 (Oracle)
- Gradle: 9.2.1
- Project Path: D:\学校资料\CS3343\project\3343-Project (contains non-ASCII characters)

## Initial Symptoms
- 202 tests total, 34-36 tests failing
- All Mockito-based tests failing with "MockitoException: Mockito cannot mock this class"
- Some business logic assertion failures

## Root Causes Identified

### 1. ByteBuddy Incompatibility with JDK 25

Error Message:
  java.lang.IllegalArgumentException: Java 25 (69) is not supported by the current version of Byte Buddy 
  which officially supports Java 22 (66) - update Byte Buddy or set net.bytebuddy.experimental as a VM property

Cause: Mockito 5.x bundles ByteBuddy 1.14.x which doesn't support JDK 25.

Solution: Force ByteBuddy 1.17.1 in build.gradle:

  configurations.all {
      resolutionStrategy {
          force 'net.bytebuddy:byte-buddy:1.17.1'
          force 'net.bytebuddy:byte-buddy-agent:1.17.1'
      }
  }

  dependencies {
      testImplementation('org.mockito:mockito-core:5.14.2') {
          exclude group: 'net.bytebuddy'
      }
      testImplementation('org.mockito:mockito-junit-jupiter:5.14.2') {
          exclude group: 'net.bytebuddy'
      }
      testImplementation 'net.bytebuddy:byte-buddy:1.17.1'
      testImplementation 'net.bytebuddy:byte-buddy-agent:1.17.1'
  }

Also add JVM args in test block:

  test {
      useJUnitPlatform()
      jvmArgs '--add-opens', 'java.base/java.lang=ALL-UNNAMED',
              '--add-opens', 'java.base/java.lang.invoke=ALL-UNNAMED',
              '--add-opens', 'java.base/java.lang.reflect=ALL-UNNAMED',
              '--add-opens', 'java.base/java.util=ALL-UNNAMED',
              '-XX:+EnableDynamicAgentLoading',
              '-Dnet.bytebuddy.experimental=true'
  }

### 2. Non-ASCII Project Path Causing ClassNotFoundException

Error Message:
  Could not execute test class 'config.DatabaseConfigTest'.
  ClassNotFoundException: config.DatabaseConfigTest

Cause: Gradle writes test argfile with default encoding; JDK reads as UTF-8. 
Chinese characters in path (学校资料) become garbled, breaking classpath resolution.

Solution: Copy project to ASCII-only path:

  Copy-Item -Recurse "D:\学校资料\CS3343\project\3343-Project" "C:\projects\3343-Project"
  cd C:\projects\3343-Project
  .\gradlew.bat clean test

### 3. Missing Dependency Injection Constructor

Error: Mockito @InjectMocks failed for FavoriteService

Cause: FavoriteService only had default constructor, no constructor accepting 
FavoriteDao and ItemDao for injection.

Solution: Added DI constructor:

  public FavoriteService(FavoriteDao favoriteDao, ItemDao itemDao) {
      this.favoriteDao = favoriteDao;
      this.itemDao = itemDao;
  }

### 4. Stale Project Copy

Symptom: Changes to D:\学校资料\...\build.gradle not reflected when running from C:\projects\...

Cause: Project was copied once but subsequent edits were made to original location only.

Solution: Re-sync project after each edit:

  robocopy "D:\学校资料\CS3343\project\3343-Project" "C:\projects\3343-Project" /E /PURGE

### 5. Database Schema Mismatch (NotificationServiceTest)

Error: SQLITE_CONSTRAINT_NOTNULL: NOT NULL constraint failed: notifications.title

Cause: Test expected NULL values for title/content, but existing database had 
old schema with NOT NULL constraints.

Solution: Recreate table in @BeforeAll:

  @BeforeAll
  static void setupDatabase() {
      DatabaseConfig.initDatabase();
      try (Connection conn = DatabaseConfig.getConnection();
           Statement stmt = conn.createStatement()) {
          stmt.execute("DROP TABLE IF EXISTS notifications");
          stmt.execute("CREATE TABLE notifications (id INTEGER PRIMARY KEY, user_id INTEGER NOT NULL, title TEXT, content TEXT, ...)");
      }
  }

## Result

  BUILD SUCCESSFUL in 9s

## Lessons Learned

1. JDK 25 is bleeding edge; always check library compatibility (especially ByteBuddy/Mockito)
2. Avoid non-ASCII characters in project paths on Windows with Gradle
3. When copying projects to new locations, always re-sync after edits
4. SQLite doesn't support ALTER TABLE to remove NOT NULL; must recreate table
